① 컬럼명 파일 불러오기

원천 데이터의 컬럼명(항목명)이 담긴 CSV·XLSX를 넣습니다. 다음 세 형식을 모두 받습니다.

  • 원천 데이터 파일 자체(첫 행이 컬럼명) — 앞부분만 읽고, 값은 화면 미리보기에만 씁니다.
  • 컬럼명을 세로로 적은 목록(한 열)
  • 항목정의서 형식(항목ID·표준항목명 열)

이 SW는 데이터를 변환하지 않습니다. 컬럼명을 표준항목에 매핑하고, 어떻게 변환할지를 Python 코드로 만들어 줍니다. 담당자가 코드를 검토한 뒤 병원 내부에서 직접 실행합니다.

파일을 여기에 끌어다 놓거나 클릭해서 선택
.csv · .tsv · .txt · .xlsx

② 매핑 검토

표준항목 칸에 항목ID나 이름을 입력하면 매핑이 바뀝니다. 변환 방식은 항목 자료형으로 정해지며 바꿀 수 있습니다.

③ Python 변환 코드 만들기

패키지: convert.py(매핑 내장 변환 코드) · 매핑표.csv · 매핑.json · run.bat · requirements.txt · README_실행안내.md. 실행하면 01_표준화.csv · 02_KRCDI_long.csv · 03_OMOP_staging.csv · 04_FHIR_staging.csv · 변환로그.csv가 만들어집니다. 직접식별자는 넣지 않고, 환자번호는 KCURE_SALT 기반 가명키로 바꾸며, 생년월일은 연도만 남깁니다.
