① 암종과 변환할 항목(컬럼) 선택

암종을 고르면 그 암종의 K-CURE 항목 전체가 선택됩니다. K-CURE가 아닌 일반 병원 데이터는 범용(비 K-CURE)을 고르세요(KR CDI V3 기반 범용 사전으로 매핑). 특정 컬럼만 변환하려면 컬럼 목록 파일을 불러오세요. 원천 데이터의 헤더 행, 컬럼명 한 줄 목록, 항목정의서(항목ID·표준항목명 열) 모두 가능합니다.

선택 항목

② 컬럼별 메타데이터 매핑 (KR CDI · KR Core · mCODE · OMOP · DCAT · ARGO)

KR CDI·KR Core·mCODE 매칭은 항목정의서(규칙승인)를 따릅니다. OMOP·ARGO 매칭은 규칙 기반 자동 후보이며 해당 칸에서 직접 고칠 수 있습니다(비우면 "미매칭"). 표가 넓으면 가로로 스크롤하세요.

매칭 용어 직접매칭=그대로 사용 · 조건부매칭=제약 추가 필요 · 상위매칭=상위 항목으로만 담김 · 참조매칭=개념·구조만 참조 · 확장필요=확장 설계 대상 · 미매칭=대응 항목 없음 · 범위외=표준 수집범위 밖 · 항목 미인식=표준항목에 연결 안 된 컬럼. 배지에 마우스를 올리면 항목정의서의 원래 판정이 보입니다.

먼저 ① 에서 암종이나 컬럼을 선택하세요.

④ 가명처리 코드 추천 (원본 미수정)

원천 데이터의 컬럼과 샘플(앞 10행)을 분석해 컬럼별 가명처리 기법을 추천합니다. 승인한 컬럼에 대해 Python·SQL·정규식 실행 코드를 만듭니다. 이 SW는 원본을 바꾸지 않습니다. 담당자가 코드를 검토한 뒤 병원 내부에서 직접 실행합니다.

추천은 규칙 기반 후보입니다. 신뢰도 '높음'만 자동으로 승인되고, 나머지는 담당자가 확인한 뒤 승인해야 코드에 들어갑니다. 가명처리 수준은 「가명정보 처리 가이드라인」과 기관 심의 기준으로 최종 판단하세요.

규칙팩 · 감사 이력

      
규칙팩은 가명처리 추천 규칙·PII 정규식을 버전과 SHA-256으로 묶은 파일입니다. 중앙에서 검증한 규칙팩을 불러오면 차이를 확인한 뒤 교체합니다(현재 창에만 적용). 감사 이력은 검토·승인·코드 생성 기록입니다. 환자 값은 담지 않고 컬럼명·규칙·해시만 남기며, 이 브라우저(IndexedDB)에 임시로 보관합니다. 기관 기록용으로 내려받아 보관하세요.
