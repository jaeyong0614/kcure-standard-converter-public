① 암종과 변환할 항목(컬럼) 선택

암종을 고르면 그 암종의 K-CURE 항목 전체가 선택됩니다. 특정 컬럼만 변환하려면 컬럼 목록 파일을 불러오세요. 원천 데이터의 헤더 행, 컬럼명 한 줄 목록, 항목정의서(항목ID·표준항목명 열) 모두 가능합니다.

선택 항목

② 컬럼별 메타데이터 매핑 (KR CDI · KR Core · mCODE · OMOP · DCAT · ARGO)

KR CDI·KR Core·mCODE 대응은 항목정의서(규칙승인)를 따릅니다. OMOP·ARGO 대응은 규칙 기반 자동 후보이며 해당 칸에서 직접 고칠 수 있습니다(비우면 "대응 없음"). 표가 넓으면 가로로 스크롤하세요.

먼저 ① 에서 암종이나 컬럼을 선택하세요.

③ 메타데이터 내려받기

선택한 컬럼의 표준별 메타데이터를 만듭니다. 패키지(zip)에는 아래 파일이 모두 들어 있고, 통합 엑셀은 컬럼별 6개 표준(KR CDI·KR Core·mCODE·OMOP·DCAT·ARGO) 대응을 한 시트에 정리하고 표준별 상세·충족 현황 시트를 더한 정의서입니다.
